# New Century Robotics Club GUI API

## Build Instructions

- 1 This project makes extensive use of C++17 features; therefore, it must be compiled using `GNU Tools for Arm Embedded Processors 8-2018-q4-major` or a newer version. Earlier versions will definitely fail to compile.
- 2 This project uses `pros library files` but does not use the `pros` development environment. Development environment users can customize it according to their preferences.
- 3 It is recommended to install an SD card on the V5 Brain. This project uses JSON data format to record all data, enabling all configurations to be changed directly on the brain.

## Usage Instructions

- Method 1:
  Directly download this project via `git clone https://github.com/3038922/ncrapi.git`
- Method 2:
  Download
  1. Download the latest ncrapi x.x.x compressed package from the releases to your pros project directory.
  2. `prosv5 c f ./ncrapi@10.x.x.zip`
  3. `prosv5 c a ncrapi@10.x.x`
